# MUN-Guide
Welcome to MUN Guide — a simple resource for learning about Model United Nations conferences.

*What This Project Does*
<li>This website explains the main MUN topics in one place:
<li>Home — overview and why MUN matters
<li>Learn MUN — UN basics and roles
<li>Committee Flow — step-by-step session timeline
<li>Documents — sample papers and formatting tips
<li>Speeches — examples and delivery advice
<li>Strategy — how to earn awards and placements
<li>Country Research — quick foreign policy summaries and reference notes

I also wanted something with simple navigation :3

*Why I made this*
<li>Most websites I've seen are either huge or narrow. I wanted a short guide that still covers the rules and UNA-USA procedure.
<li>I felt bad for new delegates who panic before their first conference. This guide is meant to help them prepare and enjoy the experience.

*Tech stack*
<li>Very basic tools
<li>HTML
<li>CSS
<li>JavaScript
<li>JSON for country data

*What I struggled with*
<li>This was the first project I built without tutorials, and it was a rollercoaster.
<li>CSS Grid — making cards line up on mobile took a lot of work.
<li>Country data — I had to learn before I could write everything.
<li>Debugging — many issues were caused by typos in the code.

*What I learned*
<li>Building websites is not as hard as it looks. I learned a lot, especially about CSS and project structure.

*Final notes*
<li>I hope you enjoy the site. If you’re scared to make your own website, try it — it can be fun and worthwhile.
